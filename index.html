MISION RELAMPAGO: PANEL DE SALUD

En el hackathon no gana el que sabe mas: gana el que arma rapido y sin trabarse. Hoy entrenamos eso.

Objetivo

Al terminar vas a poder armar en Node-RED, en minutos, un panel de signos vitales con semaforo, MQTT y check-in, y vas a saber cuanto tardaste en cada paso para bajar ese tiempo la proxima vez.

La analogia: es como un pit stop de Formula 1. El auto ya sabe correr; lo que se entrena es cambiar las cuatro ruedas en segundos. Hoy cronometramos nuestro "pit stop" de SCADA.

Reglas del juego

  • Parejas: uno es piloto (maneja el teclado) y otro copiloto (lee la guia y controla el reloj). Se cambian en cada ronda.
  • Cronometro: el copiloto anota el tiempo de cada ronda en la tabla del final.
  • Prohibido copiar y pegar el flow de rescate antes de intentarlo por su cuenta. Es el paracaidas, no el avion. Si pasan el tiempo limite, lo usan y anotan "rescate".
  • Dashboard: se ve en http://localhost:1880/ui (o la IP de la compu donde corre Node-RED).

Necesitan tener instalado node-red-dashboard (menu, Manage palette, Install).

RONDA 1: Pulso en pantalla meta: 10 min

Armar este camino: inject (cada 2 s) → function → gauge.

// Nodo function: simula un pulso entre 65 y 80
msg.payload = Math.round(65 + Math.random() * 15);
return msg;
Mini-mision: gauge de 40 a 140 lpm que se actualice solo. Mostralo en /ui.

RONDA 2: Semaforo personal meta: 15 min

Un valor "alto" depende de cada persona. Compara contra la linea base, no contra un numero fijo.

// Nodo function: semaforo para un solo valor
const base = 70;                                    // linea base del astronauta
const desvio = Math.abs(msg.payload - base) / base * 100;   // % de desvio

if (desvio <= 10)      { msg.estado = "VERDE";    msg.color = "#00e676"; }
else if (desvio <= 20) { msg.estado = "AMARILLO"; msg.color = "#ffd600"; }
else                   { msg.estado = "ROJO";     msg.color = "#ff5252"; }
return msg;

Mostralo con un nodo ui_template:

<div style="text-align:center;font-size:30px;font-weight:bold;padding:14px;
            border-radius:14px;color:#000;background:{{msg.color}}">
  {{msg.estado}}
</div>
Mini-mision: agrega un slider de "estres" (0 a 100) que haga subir el pulso simulado: 70 + estres * 0.4. Mueve el slider y mira cambiar el color.
Ojo: los porcentajes son didacticos, no medicos. En el pitch se dice siempre.

RONDA 3: MQTT, la nave habla meta: 15 min

Hasta ahora todo pasa dentro de una sola compu. En una nave real el sensor y el panel estan separados: se comunican por MQTT. Es como una radio: uno transmite en una frecuencia (topico) y otro la sintoniza.

  1. Despues de la function que simula, agrega un nodo mqtt out. Broker: broker.hivemq.com, puerto 1883.
  2. Topico (cambia equipoX por el nombre de tu equipo, asi no se mezclan): i9/spaceapps/equipoX/vitales
  3. Agrega un mqtt in con el mismo broker y topico, y conectalo al semaforo.
  4. Para que viaje todo junto, publica un objeto JSON:
// Nodo function antes del mqtt out
msg.payload = {
  pulso: Math.round(65 + Math.random() * 15),
  spo2: 98,
  temp: 36.6
};
return msg;      // el nodo mqtt out lo convierte a texto JSON solo
Mini-mision: hagan que el piloto de un equipo publique y la pantalla del equipo de al lado reciba. Cambien el topico por el del companero.
Plan B sin internet: el broker publico necesita conexion. Si falla, instalen mosquitto local en una compu (mosquitto -v) y usen su IP como broker. Esto tambien hay que tenerlo resuelto antes de viajar.

RONDA 4: Check-in del astronauta meta: 15 min

Los datos fisicos no cuentan todo. El desafio habla de aislamiento y salud mental, asi que sumamos un chequeo diario.

  1. Agrega dos nodos ui_slider: Sueno (0 a 10) y Animo (0 a 10).
  2. Guarda cada valor con un nodo change en flow.sueno y flow.animo.
  3. En la function del semaforo, agrega una regla combinada:
// Regla combinada: varias senales juntas pesan mas que una sola
const sueno = flow.get('sueno') ?? 8;
const animo = flow.get('animo') ?? 8;

if (msg.estado === "VERDE" && (sueno <= 4 || animo <= 4)) {
  msg.estado = "AMARILLO";                       // cuerpo bien, pero animo/sueno bajos
  msg.color = "#ffd600";
  msg.accion = "Check-in: revisar sueno y animo";
}
if (msg.estado === "AMARILLO" && sueno <= 4 && animo <= 4) {
  msg.estado = "ROJO";                           // todo junto: escalar
  msg.color = "#ff5252";
  msg.accion = "Alerta: contactar a Tierra";
}
return msg;
Mini-mision: logren que un astronauta con pulso normal pase a AMARILLO solo por dormir mal. Esa es la idea fuerte para el pitch.

RONDA FINAL: Demo de 60 segundos

Cada pareja muestra su panel y cuenta en un minuto: que mide, como decide y que haria el astronauta. El resto del curso levanta la mano si entendio el semaforo sin ayuda. Si alguien no entendio, hay que mejorar la explicacion.
